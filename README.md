# Data Management Table (Test Task)

A robust, high-performance web interface for managing and editing structured data.

👉 **[View Live Demo on GitHub Pages](https://igorok-by.github.io/data-management-table/)**

## Purpose

This application provides a professional-grade data grid with advanced editing capabilities, optimized for handling large datasets with zero performance lag and full type safety.

## Tech Stack

- **Core:** React 19, TypeScript 5.9
- **UI:** Material UI (MUI)
- **Utilities:** Dayjs (Date handling), Vite (Build tool)
- **Deployment:** GitHub Actions
